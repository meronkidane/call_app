# StreamHub TV (React Native TV)

A React Native TV interface targeting Android TV and Apple tvOS devices.

## Getting Started

```bash
cd app/frontends/tv-react-native
npm install
npm run start
```

Use `npm run android` or `npm run ios` with the TV emulators to run the experience. The app demonstrates D-pad navigation and focus rings with placeholder catalog data.
